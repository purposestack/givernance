Spécification — bannière « Ajouter un logo » (AddLogoBanner)

Anatomie. Bande ambre (--color-amber-light, bordure basse --color-amber-border, texte --color-amber-text) montée au-dessus du topbar, dans la colonne de contenu (jamais par-dessus la sidebar). Icône add_photo_alternate, corps centré, CTA outline tertiaire vers /settings#branding (section logo intégrée à la carte Organisation — pas de hero card dédié), bouton fermer 28×28.
Règles de visibilité. Visible uniquement si : (1) rôle org_admin — un non-admin ne peut pas agir, donc ne voit rien ; (2) aucun logo actif côté serveur ; (3) pas de fermeture dans la session courante. La fermeture est stockée en sessionStorage par organisation (gv.add-logo-banner.dismissed.<orgId>) — la bannière revient à la prochaine session tant qu'aucun logo n'est configuré (même patron que la bannière admin provisoire). L'upload d'un logo la retire immédiatement.
Réutilisation. Toute future incitation d'onboarding (« Connecter Stripe », « Vérifier votre domaine », …) DOIT réutiliser cette anatomie : même position (au-dessus du topbar, sous les bannières impersonation/admin provisoire), mêmes jetons ambre, même mécanique de fermeture par session et par org. Une seule bannière d'onboarding visible à la fois (ordre d'empilement = ordre de monté dans l'AppShell).
Contraintes d'upload (canoniques, alignées implémentation). Formats acceptés : PNG, JPEG, WebP — 5 Mo max ; SVG — 1 Mo max (sanitisé côté serveur : scripts, imbrication et nombre d'éléments plafonnés). Les variantes (sidebar 128×128, favicon, PDF) sont produites par le pipeline worker (ADR-024).

Spécification — avatar initiale (InitialLetterAvatar)

Partout où une organisation doit être identifiable avant (ou en l'absence de) logo : sidebar, carte logo des réglages, lignes du sélecteur d'organisation, hero de la page de don publique. La couleur est déterministe : hash multiplicatif-31 du tenantId (repli : nom de l'org) → index dans la palette fixe de 8 couleurs ci-dessous. Même org → même couleur, sur toutes les surfaces et toutes les sessions. L'ordre de la palette est contractuel : le changer remélangerait la couleur de toutes les orgs existantes. Chaque fond passe WCAG AA (≥ 4,5:1) contre le glyphe blanc. Décoratif par défaut (aria-hidden) ; devient role="img" + label quand il porte seul l'identité (page de don publique).
