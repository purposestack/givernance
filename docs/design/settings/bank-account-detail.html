Status pill semantics (§5.1)

pending = file accepted, in outbox · imported = XSD-valid, entries persisted · processing = reconciler running · processed = done · failed = XSD invalid or foreign IBAN · duplicate = same MsgId already imported (idempotency short-circuit).

GDPR posture (§7)

IBAN truncated to last 4 (CH··· 8901·2) on listing views; full IBAN only on the form. Raw XML stored in the bank-statements private bucket with signed-URL access only; 10-yr retention per Swiss CO Art. 958f.

Health card data source

Rolling 90-day aggregate from camt_statements + camt_credit_entries + camt_unreconciled_entries. Cached 60 s; refreshes on any new upload.

Drill-down

Clicking a row opens bank-statement-detail.html. Clicking the queue CTA opens camt-unreconciled-queue.html filtered to this bank account.
