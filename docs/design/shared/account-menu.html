Menu compte

SHARED-001 · Dropdown du topbar — déclenché par l'avatar utilisateur

Contexte. Le PR #73 a posé un bouton LogOut temporaire dans le pied de la sidebar parce qu'aucune maquette ne couvrait un menu compte. Cette maquette définit le menu déroulant ancré sur l'avatar du topbar : identité, accès rapide aux paramètres personnels, sélecteur de langue, déconnexion. Une fois implémenté, le bouton temporaire de la sidebar est retiré.

Issue de référence. #76 — Account menu UX + back-channel logout · PR-1 Step 1.

1. Dans le contexte du topbar

Le déclencheur remplace l'actuel <Link href="/settings"> autour de l'avatar dans le topbar. Le menu s'ouvre au clic ou via la touche Espace / Entrée lorsque l'avatar a le focus.

2. États du déclencheur

L'avatar a quatre états visuels distincts : repos, survol souris, ouvert, focus clavier. Tous utilisent uniquement box-shadow pour ne pas faire bouger le voisinage.

Repos

default

État par défaut. Aucune ombre, juste la couleur primaire et les initiales.

Survol souris

:hover

Halo doux (rgba primary 10%) — signal qu'on peut cliquer, sans agression visuelle.

Menu ouvert

aria-expanded

Halo renforcé (15%) tant que le menu est visible. Persiste pendant la navigation clavier dans le menu.

Focus clavier

:focus-visible

Anneau de focus standard (--focus-ring) — distinct du survol souris pour respecter :focus-visible.

3. États du menu

Le menu réutilise les primitives .dropdown-menu et .dropdown-item du design system, étendues avec : en-tête identité, séparateurs, sélecteur de langue, item destructif final.

Ouvert — état nominal

opened

Aucun item survolé ni focalisé. Le sélecteur de langue indique le choix actif via aria-current="true" + coche.

4. Spécification

Ce qu'attend l'implémentation React. Le composant cible utilisera @radix-ui/react-dropdown-menu via la primitive shadcn/ui (ADR-012) — Radix gère l'a11y, on apporte les styles ci-dessus.

Structure du menu (de haut en bas)

  • En-tête identité : avatar 40px + nom complet + email, non cliquable, troncature avec text-overflow: ellipsis si débordement.
  • dropdown-divider
  • Mon compte — lien vers /account (préférences personnelles, distinct de /admin).
  • dropdown-divider
  • Section Langue — label discret + 2 items radio FR / EN, choix actif marqué aria-current="true" + coche.
  • dropdown-divider
  • Se déconnecter — item destructif, icône logout, déclenche useAuth().logout().

Accessibilité (WCAG 2.1 AA)

  • Le déclencheur est un <button> (pas un <a>) avec aria-haspopup="menu" et aria-expanded dynamique.
  • Le menu a role="menu" ; les liens ont role="menuitem" ; les items langue ont role="menuitemradio" avec aria-checked.
  • Le focus est piégé dans le menu tant qu'il est ouvert (gestion native par Radix). Tab et Maj+Tab sortent du menu en le fermant.
  • Touches : ↑/↓ pour naviguer, Enter/Espace pour activer, Esc pour fermer et rendre le focus au déclencheur, Home/End pour aller au premier/dernier item.
  • Contraste : texte primaire --color-text sur --color-surface-container-lowest = 16.4:1 ; item destructif --color-error sur fond clair = 5.8:1 (≥ AA 4.5:1).
  • Le clic en dehors du menu le ferme. Sur mobile (largeur ≤ 640px), même bottom-sheet pattern via Radix.

Comportement

  • Déconnexion : appelle useAuth().logout() qui POSTe sur /api/auth/logout. Le côté front efface ensuite givernance_session, givernance_csrf, puis redirige vers Keycloak avec id_token_hint (déjà câblé par PR #73).
  • Mon compte : navigue vers /account (page à implémenter ; pour l'instant, redirection silencieuse vers /admin/organization tant que la page personnelle n'existe pas — à confirmer en review).
  • Changement de langue : appelle next-intl's setRequestLocale via une route helper et recharge la page avec le préfixe locale correct. Persisté côté serveur dans givernance_locale cookie.
  • Sidebar logout : la version icône du footer sidebar est supprimée dans le même PR — le menu compte devient l'unique point de sortie.

Tokens utilisés

  • Conteneur : --color-surface-container-lowest, --radius-lg, --shadow-elevated.
  • Bordure : --color-outline-variant.
  • Item destructif : --color-error + --color-error-container au survol.
  • Animation entrée : --duration-normal + --ease-out.
  • Espacement : --space-2 (8px) padding vertical item, --space-3 (12px) padding horizontal.
  • Aucun token nouveau introduit — réutilisation pure du design system existant.
